# SG - PS videos

Motion videos built as HTML scenes (every frame is `render(t)` of time t), rendered frame by
frame with headless Chromium and encoded with ffmpeg; the music is generated by `music.py`.

- `promo.html`: 31 s promo (features, browser and desktop, call to action).
- `fixes.html`: 42 s before / after of the bug-fix round.

Render (from this folder; needs Node + Playwright with Chromium, ffmpeg, Python + numpy):

```bash
python3 music.py promo.wav 31 3.2,7.8,12.2,16.6,21.2,25.6 112
node render.mjs promo.html promo-noaudio.mp4 30
ffmpeg -i promo-noaudio.mp4 -i promo.wav -c:v copy -c:a aac -b:a 192k -shortest promo.mp4

python3 music.py fixes.wav 41.8 3.6,7.8,12.0,16.2,20.4,24.6,28.8,33.0,37.2 116
node render.mjs fixes.html fixes-noaudio.mp4 30
ffmpeg -i fixes-noaudio.mp4 -i fixes.wav -c:v copy -c:a aac -b:a 192k -shortest fixes.mp4
```

`node render.mjs page.html --stills 1.0,5.0` writes single frames to `stills/` for checking.
`a/` holds the screenshots and artwork, `fonts/` the Cairo font files.

## Sound effects only (no music)

`sfx.py` synthesises motion sounds (whooshes, impacts, pops, clicks, chimes...) at the times listed
in `promo-sfx.json` / `fixes-sfx.json`, synced to the animations:

```bash
python3 sfx.py promo-sfx.wav 31 promo-sfx.json
ffmpeg -i promo-noaudio.mp4 -i promo-sfx.wav -c:v copy -c:a aac -b:a 192k -shortest SG-PS-promo-sfx.mp4
python3 sfx.py fixes-sfx.wav 41.8 fixes-sfx.json
ffmpeg -i fixes-noaudio.mp4 -i fixes-sfx.wav -c:v copy -c:a aac -b:a 192k -shortest SG-PS-update-before-after-sfx.mp4
```

## Install guide (first launch on macOS and Windows)

`tutorial.html` (58.5 s): step-by-step first launch, with replicas of the macOS "Not Opened" dialog,
System Settings > Privacy & Security > Open Anyway, and the Windows SmartScreen screen. The cursor
finds its targets from the page elements, so layout changes keep the clicks on the buttons.

```bash
python3 sfx.py tutorial-sfx.wav 58.5 tutorial-sfx.json
node render.mjs tutorial.html tutorial-noaudio.mp4 30
ffmpeg -i tutorial-noaudio.mp4 -i tutorial-sfx.wav -c:v copy -c:a aac -b:a 192k -shortest SG-PS-install-guide.mp4
```
