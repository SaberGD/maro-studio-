# HORIX One landing-page screenshots

Captured from the public HORIX One web app on 2026-11-17. These are actual
application screenshots, not reconstructed UI or generated product mockups.

- `assets/screens/one-vector-20261117.jpg`: an original demonstration composed
  using Vector's rectangle, ellipse and type tools (ONE IDEA).
- `assets/screens/one-pixel-20261117.jpg`: that same document after using One's
  **Open design in Pixel** action; it opens as shape layers.
- `assets/screens/one-layout-20261117.jpg`: the **Sample magazine** bundled with
  Layout, a separate document. The landing page explicitly identifies it as such.

Source app: https://one.horix.live/ (Vector / Pixel / Layout).
App licenses remain at https://horix.live/LICENSE.txt and the repository's
third-party notices. The existing family concept assets are retained for other
uses but are no longer used as evidence on the landing page.
